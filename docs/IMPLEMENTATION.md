# 实现说明

工具将 Markdown 解析为逐页内容，再按固定坐标生成 PPTX。`convert.mjs` 负责分页、内容解析、空间估算和排版，`src/formula.mjs` 将受支持的公式转换为线性文本。PPTX 使用 pptxgenjs 生成，本地图片尺寸使用 image-size 读取。

## 内容与排版

每页恰有一个二级标题，以独占一行的 `---` 分页。`### 讲解 notes` 之后的内容完整写入 speaker notes。图片相对于 Markdown 定位，等比例缩放并嵌入文件；缺少图片时报错。表格按列对齐，以可编辑文本框及横线绘制。

画布为 16:9。标题固定 26 pt，正文在允许的字号内估算高度；内容超出时明确失败。以“研究内容”开头的标题使用深色章节页。具体语法及限制见 [FORMAT.md](../FORMAT.md)。

## 运行入口

Windows/Linux 共用 `convert.mjs`。`ubuntu.sh` 仅处理环境检查、依赖安装和命令转发，`run.sh` 为别名，不维护第二套转换实现。

默认读取本机字体：Windows 为 Microsoft YaHei，Linux 为 Noto Sans CJK SC。可通过 `PPTX_FONT_SANS` 覆盖。字体不嵌入 PPTX，目标机器字体替换可能影响换行。

## 验证

测试解析通用示例并转换，读取实际生成的 PPTX ZIP，核对页数、正文、表格单元格、备注、图片对象及嵌入的图片字节。同时覆盖错误输入和防覆盖行为。页面底边使用排版估算检查，不等同于真实渲染的像素级验证。

输出采用独占创建以防覆盖现有 PPTX。审计文件保存输入绝对路径和逐页布局信息，属于本地输出，不应未经检查直接发布。
